# Астананың соңғы сигналы

**Qazaq AI Research University · AI Fundamentals · Final Project**

3D браузерлік шытырман ойында QAIRU студенті мен QairuBot SANA жүйесінің неге өшкенін анықтайды. Ойыншы университеттен шығып, Астана арқылы EXPO-ға барады және дәлелдер жинайды. Сюжет пен деректер ойдан шығарылған.

**[Ойынды браузерде ашу](https://qairu-last-signal.honedflint1.chatgpt.site)**

![Ойынның мұқаба иллюстрациясы](dist/hero.png)

## Жобаның мақсаты

Жасанды интеллект пәніндегі әдістерді ойын тапсырмалары арқылы көрсету. Ойыншы код шарттарын тексереді, картадағы жолдарды өзгертеді және табылған дәлелдердің ықтималдыққа әсерін көреді. AI LAB-та жіктеу моделінің сапасын салыстырады.

## Ойындағы ЖИ тақырыптары

| Апта | Тақырып | Ойыншының әрекеті | Алгоритм нәтижесі |
|---|---|---|---|
| 2 | A* және эвристикалық іздеу | Картадағы көшелерді ашады немесе жабады | Жол, қадам саны және қаралған торкөз саны |
| 3 | Шектеулерді қанағаттандыру (CSP) | Есікке код енгізеді немесе көмек сұрайды | Шарттардың орындалуы және кері шегіну арқылы табылған код |
| 6 | Байес ықтималдығы | Дәлелдерді жинайды | Үш нұсқаның жаңартылған ықтималдығы |
| 8 | Жіктеу және модельді бағалау | AI LAB-та дабыл шегін өзгертеді | Confusion matrix, Accuracy, Precision, Recall, F1 |

Accuracy, Precision, Recall және F1 — алгоритм емес, жіктеу сапасын өлшейтін көрсеткіштер. AI LAB-та наивті Байес жіктеуіші бар. Негізгі үш түрлі аптаның тақырыптары: 2, 3 және 6.

## Қалай ойнауға болады

1. Ойын сілтемесін WebGL қолдайтын браузерде ашыңыз.
2. **Ойынды бастау** батырмасын басыңыз.
3. Жарық белгіге жақындап, E басыңыз. Алдымен QairuBot-пен сөйлесіңіз.
4. QAIRU есігін ашып, картадан EXPO-ға жол тауып, сервер бөлмесіндегі дәлелдерді тексеріңіз.
5. Әр тараудағы көгілдір белгілерден қосымша құпия хабарлар табуға болады.

| Басқару | Әрекет |
|---|---|
| W A S D | Жүру |
| Тінтуір немесе ← → | Айналаға қарау |
| E | Затпен әрекеттесу |
| Shift | Жүгіру |
| Esc | Тінтуір курсорын босату |

Тінтуірмен қарау үшін ойын алаңын басыңыз. Бөлімдер мен табылған дәлелдер браузерде сақталады. Толық ақпарат: [docs/USER_GUIDE.md](docs/USER_GUIDE.md).

## Бастапқы кодты іске қосу

Python 3 орнатылған болса, жоба бумасында:

```bash
python -m http.server 8000
```

Содан кейін браузерде `http://localhost:8000/dist/` мекенжайын ашыңыз. Кейбір жүйелерде `python3 -m http.server 8000` қолданылады. Ойынға WebGL қолдайтын браузер керек. Three.js 0.180.0 файлдары жобамен бірге берілген, лицензиясы `dist/vendor/THREE-LICENSE.txt`. Google Fonts интернет арқылы жүктелуі мүмкін, қолжетімсіз болса жүйелік қаріп қолданылады. API кілті қажет емес.

## Жүйе құрылымы

- `dist/index.html` — ойын беті және басқару элементтері.
- `dist/game3d.js` — 3D көрініс, ойын логикасы және негізгі алгоритмдер.
- `dist/game3d.css` — интерфейс безендірілуі.
- `dist/vendor/` — Three.js кітапханасы және лицензиясы.
- `tests/game3d-logic.test.cjs` — алгоритмдерді тексеру.
- `docs/` — архитектура, сынақ нәтижелері және дереккөздер.
- `submission/` — есеп пен қорғау материалдарының **тексеруді қажет ететін жобалары**.

3D әлемі мен алгоритмдер браузерде JavaScript арқылы жұмыс істейді. Python бөлек алгоритм сервері ретінде қолданылмайды. Толығырақ: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Автоматты сынақтар

Node.js орнатылған болса, жоба бумасында орындаңыз:

```bash
node tests/game3d-logic.test.cjs
node tests/algorithms.test.cjs
```

Тестілеу туралы: [docs/VERIFICATION.md](docs/VERIFICATION.md). Автоматты алгоритм сынақтары 3D ойынды браузерде толық қолмен тексерудің орнын баспайды.
